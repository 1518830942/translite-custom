## 下载安装

- **Windows 10/11 x64**：下载 `win-x64-setup.exe`，运行安装，默认快捷键 **Alt+E**。
- **Apple 芯片 Mac**：下载 `mac-arm64.dmg`，将 Translite 拖入“应用程序”，默认快捷键 **Control+D**；ZIP 提供相同应用。
- 首次启动填写自己的 API 地址、密钥和模型。已有安装保留保存的快捷键与配置。

## 本次更新

- 修复 Windows 快速按 Alt+E 后因松键顺序导致源软件菜单抢走焦点、取词失败并显示旧记录的问题。识别菜单后恢复正文焦点，旧式 Windows 菜单补齐兼容处理。
- 增加真实快捷键回归：覆盖两种松键顺序、1/15/250 毫秒按键、Chromium 和独立 Windows 文本窗口；确认未选中文字时不发送 Ctrl+C，且普通正文选区不会被 Escape 清除。
- 第一轮性能优化：译文边返回边显示，完整音标在结果完成时补齐；正确处理结束标记，避免回复已结束却仍等待连接关闭。
- 最新查询立即接替旧查询，相同进行中查询共用请求，迟到结果不再覆盖新内容。
- 补齐取消与超时终态；首次内容等待 20 秒、响应间隔 15 秒、总耗时 60 秒。翻译按钮在请求中变为“停止翻译”，输入框可继续编辑、按 Enter 提交新内容。
- 成功译文和音标使用有界内存缓存：128 条、4 MiB 内容预算、5 分钟有效期；翻译源、模型、模式、目标语言及提示词变更不会误用旧结果。失败和未完成结果不缓存。
- 日志写盘改为异步诊断，写入失败不影响翻译结果。
- 点击翻译窗口外使其失去焦点时自动隐藏，保留翻译内容；下次按快捷键再次取词并显示。
- 自动隐藏不会退出程序，也不受关闭按钮的“退出应用”设置影响；取消尚未完成的 Windows 前台唤醒，避免隐藏后被拉回。
- 两端快捷键唤出的窗口跟随触发时的鼠标位置；靠近屏幕右侧、底部时自动避让，支持多显示器及缩放。
- 定位发生在取词完成后，有选区、无选区和窗口最小化时均适用。
- Windows 优先查询当前选区；确认没有选中文字时，仅打开窗口，不发送 Ctrl+C、不等待剪贴板。有选区仍保持一键翻译。
- 不支持选区查询或查询超时的应用，仍沿用兼容取词流程。
- 保留 Windows 前台唤醒、英美音标、专有名词拼读参考，以及 Mac 快捷键录制和 Dock 恢复修复。
- Mac 同步支持鼠标附近弹窗，默认快捷键仍为 Control+D。

## 验证与说明

- 两端分别在 GitHub Windows/macOS 环境构建，并检查类型、平台逻辑和打包后的运行时启动；Mac 同时检查 arm64 架构。
- Windows 选区优化已在开发电脑的普通文本框和启用原生 UIA 的 Chromium 测试中验证；不代表所有第三方应用均支持快速查询。
- Mac 仍为未进行 Developer ID 签名和 Apple 公证的测试包，辅助功能授权、真实浏览器选区及全屏桌面行为需在使用者的 Mac 上确认。首次打开可能需要在“隐私与安全性”中允许打开，并授权辅助功能。
- 音标由配置的 AI 提供；推测读音不是官方读法。
- 安装包不含 API 密钥、公司配置或个人翻译记录。随附两端 SHA256 校验文件。
